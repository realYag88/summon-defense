# サモンディフェンス

魔術師の卓上遊戯。木のテーブルに広げた手描きの地図の上で、カードから魔物を召喚して道を守るタワーディフェンスです。

- カードを沿道に置くと、その上にキャラが浮かび上がって敵を攻撃します
- 同じ種族を重ねると進化(場でも手札同士でも)
- 敵にもじゃんけんの手があり、勝てば2倍・負ければ半分のダメージ
- 敵を倒すと召喚士の経験値。レベルアップでカード・スキル・強化から1つ選ぶ
- はじめにカードの束を3つから1つ選び、その束の5種族で戦う

スマホの縦持ちとPCのブラウザで遊べます。

## 遊ぶ

GitHub Pages で公開する場合は、リポジトリの Settings → Pages で `main` ブランチのルートを指定してください。

手元で遊ぶときは `index.html` をブラウザで開くだけで動きます(ビルド不要)。

## ファイル構成

```
index.html            画面の骨組み
css/style.css         見た目
js/game.js            ゲーム本体(調整値は冒頭の T と SKILL にまとめてある)
data/cards.js         カードと手アイコンのデータ(tools/build-cards.js で生成)
assets/table.jpg      背景の机
assets/map1.jpg       盤面の地図(ステージ1・村はずれ)
tools/build-cards.js  カードデータの生成スクリプト
```

## カードを増やす

カードの絵とステータスは「怪談じゃんけん」(DotRoguelikeCardBattle)の `index.html` から抜き出しています。

1. `tools/build-cards.js` の `PAIRS` に `["進化前", "進化後"]` を足す(名前は怪談じゃんけんのカード名)
2. 次を実行して `data/cards.js` を作り直す

```
node tools/build-cards.js ../DotRoguelikeCardBattle/index.html
```

コストは元のコスト(0〜3)から 1〜8 に自動で変換されます。

## 地図を増やす

地図は2:3の画像を `assets/` に置き、`js/game.js` の `PATH`(道の折れ点。マスの中心を 0.5 刻みの座標で指定)を地形に合わせて引き直します。盤面は6列×9段です。
